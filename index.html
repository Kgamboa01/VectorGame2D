Conceptos matemáticos aplicados

Aprende los fundamentos matemáticos utilizados en la simulación.

↗

Vectores en R²

Un vector representa una cantidad que posee dos componentes: una dirección horizontal X y una dirección vertical Y.

A = (x, y)
×

Producto por escalares

Consiste en multiplicar cada componente del vector por un número real, modificando su magnitud y posiblemente su dirección.

αA = (αx, αy)
+

Suma de vectores

Se suman las componentes correspondientes de dos vectores para obtener un nuevo vector.

A + B = (Ax + Bx, Ay + By)
∑

Combinación lineal

Permite construir un vector mediante la suma de otros vectores multiplicados por factores escalares.

R = αA + βB
√

Magnitud de un vector

Representa la longitud del vector y se obtiene utilizando sus componentes mediante el teorema de Pitágoras.

|R| = √(Rx² + Ry²)
